# Frontend Design Standards

1.  **Modern Aesthetics**: Use vibrant colors, dark modes, glassmorphism where appropriate, and ensure high-quality, premium visual impact.
2.  **Typography & White Space**: Rely on robust typography (e.g., Inter, Roboto) and generous padding/margins to let the layout breathe.
3.  **Dynamic Interactivity**: Incorporate micro-animations (e.g., button hovers, subtle entrance fades) to make the application feel alive and responsive.
4.  **Component Reusability**: Build UI with a single source of truth for styles. Avoid inline styles; use clean standard CSS/Tailwind abstractions.
5.  **Mobile-First Responsive**: All components must flow elegantly down to mobile device widths without scrollbars or clipped content.
