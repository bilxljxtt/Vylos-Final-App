# Concise Planning Standards

1.  **Direct to the Point**: Plans must outline what is changing, why, and exactly where (file paths). Avoid fluff and long introductions.
2.  **Visual Structure**: Use markdown lists, code blocks, and clear headers to make scanning easy.
3.  **Clear Pre-requisites**: Always identify dependencies before executing.
4.  **Verification Steps**: Every plan should have a brief test or validation section.
5.  **Focus on Value**: Do not over-engineer; prioritize the core objective set by the user.
